Como ler: cada câmera calibrada tem a sua cor: notebook · NAO · apresentação. O círculo é a posição estimada e o rastro mostra os últimos 2 segundos. No robô, a parte destacada é a que as câmeras indicam. A borda verde e “Olhando” indicam o alvo reconhecido pela combinação das câmeras. O alvo pode ser reconhecido mesmo quando a posição do ponto é imprecisa ou indisponível.

Os mapas vêm da página de alvo (notebook · TV), um por câmera, e ficam salvos por participante. É uma estimativa por webcam (normalmente 150 a 450 px de erro numa tela de notebook). Não confirma atenção nem compreensão. Esta aba não precisa da página de alvo aberta durante a apresentação.

Conectar o notebook e a câmera da apresentação

  1. Baixe o cliente e extraia a pasta no computador que tem a webcam.
  2. Execute iniciar_cliente.bat. É necessário Python 3.
  3. Informe o endereço LAN deste servidor e o código de acesso.
  4. Volte a “Câmeras e sessão”, escolha as câmeras e aplique.
Baixar conectores ZIP ↓

As webcams aparecem como “nome do computador / Webcam 0, 1…”. Confira cada imagem após selecionar. Uma câmera conectada ao servidor também usa esse cliente.

A câmera de outro notebook não aparece como webcam local do servidor. O conector envia apenas as câmeras selecionadas no painel, sem áudio.

CÂMERA INTERNA DO ROBÔ

Conectar o NAO

Copie nao_client.py para o robô e execute em um terminal com NAOqi disponível:

Informe o mesmo código e selecione NAO / câmera superior no painel. O robô envia JPEG e a pose da cabeça; o servidor faz a análise.
Se usar o SDK em outro computador, acrescente --robot IP_DO_NAO. O conector é compatível com Python 2.7 do NAOqi clássico. Confirme a versão instalada no seu robô.
Mantenha a cabeça do NAO na pose calibrada. Uma mudança superior ao limite configurado faz a leitura daquela câmera ficar indeterminada.

        
Acesso à rede local
Abra no notebook o endereço IP do servidor com a porta 8765. O endereço localhost só funciona neste computador.
Use uma rede local controlada. Nesta configuração HTTP, imagens e código trafegam sem cifragem. O navegador controla o painel; a captura é feita pelos conectores, sem exigir acesso à webcam via página HTTP.
